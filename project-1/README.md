
# Global Super Store

## Project Overview

This project involved creating a comprehensive Power BI dashboard using the Global Super Store dataset, which contains around 50,000 customer-centric sales records from multiple vendors and markets. The dashboard features data cleaning, calculated metrics, and visualizations such as shape maps and clustered charts to analyze sales performance and profit margins over time.

---

## Business Problem

Retail businesses need to analyze large volumes of sales data across vendors and markets to identify trends and profitability. Without effective visualization and analysis, decision-makers struggle to optimize sales strategies and improve profit margins.

---

## Objective

- Load and clean a large retail sales dataset for analysis
- Create calculated metrics to measure sales and profit performance
- Develop interactive visualizations to track sales trends and geographic performance

---

## Tools & Technologies

- Power BI Desktop
- Excel
- DAX (Data Analysis Expressions)
- Shape Map Visual
- Clustered Column and Line Charts

---

## Project Workflow

- Import and load the Global Super Store Excel dataset into Power BI
- Clean data by removing unwanted columns and correcting data types
- Create a date table and define relationships for time-based analysis
- Develop calculated columns and measures for sales and profit KPIs
- Build and format interactive visualizations including maps, slicers, and charts

---

## Key Insights

- Gross Profit Margin % varies significantly by country and market
- Year-over-year profit margin trends highlight growth and decline periods
- Monthly sales and profit trends reveal seasonal patterns
- Interactive slicers enable dynamic analysis across years and metrics
