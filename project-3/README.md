
# The Effect of Holiday Sales on Walmart Using ML

## Project Overview

This project analyzed Walmart sales data from 2010 to 2012 to understand the effect of holidays on sales performance using Power BI and machine learning techniques. It involved data import, transformation, DAX measure creation, and dashboard visualization to deliver actionable insights. The solution enabled clear visualization of sales trends and holiday impacts for strategic decision-making.

---

## Business Problem

Walmart needed to understand how holiday periods influenced their sales to optimize inventory and marketing strategies. Without clear insights, the company risked inefficient resource allocation during key sales periods. The project aimed to quantify and visualize these holiday effects to support better business planning.

---

## Objective

- Import and prepare Walmart sales data for analysis in Power BI
- Create calculated columns and DAX measures to identify holiday impacts
- Develop an interactive dashboard to visualize sales trends during holidays

---

## Tools & Technologies

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query Editor
- CSV Data Files
- Microsoft Office

---

## Project Workflow

- Import Walmart sales CSV data into Power BI Desktop
- Create calendar and conditional columns to flag holidays
- Establish relationships between sales and calendar tables
- Develop DAX measures to calculate sales and CPI year-over-year changes
- Design and deploy a comprehensive Power BI dashboard with logos and titles

---

## Key Insights

- Holiday periods such as Christmas and Thanksgiving significantly increase Walmart sales.
- Sales trends show distinct seasonal patterns aligned with major holidays from 2010 to 2012.
- Unemployment rate and CPI metrics were integrated to contextualize sales performance.
- Custom sorting and conditional columns improved clarity in holiday sales analysis.
